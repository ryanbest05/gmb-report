GMB Ops 개인정보처리방침

수집·접근하는 정보와 목적

GMB Ops는 권한을 가진 운영자의 Google Business Profile 관리 업무를 위해 OAuth로 관리 계정·프로필 식별자, 매장 코드(storeCode), 매장명(title)과 프로필 메타데이터를 조회합니다. 리뷰 식별자, 리뷰어 표시 이름, 리뷰 본문, 별점, 작성·수정 시각, 소유자 답글과 승인 상태를 조회하여 미응답 리뷰를 찾고 답글 초안·게시 확인·운영 이력을 관리합니다. 로컬 게시물의 내용, 식별자, 게시 시각과 공개 상태도 조회하고 게시에 사용합니다.

보관 및 접근

OAuth 갱신 자격 증명(refresh token)은 운영자 VPS의 로컬 파일에 보관하며 파일 권한은 0600으로 제한합니다. 로컬 운영 데이터와 자격 증명에 대한 관리 접근은 권한을 가진 운영자로 제한합니다. 리뷰·답글·게시 대기열, 처리 로그와 운영 이력은 로컬에 보관합니다. 아래 외부 서비스 전달 및 Google에 공개 게시하는 처리는 이 관리 접근 제한과 별개입니다.

AI 및 외부 서비스로의 전달

  • OpenAI: 리뷰 본문·별점·매장명과 과거 리뷰·소유자 답글 예시를 답글 생성에 전달합니다. 게시물 작성용 매장 정보·원고와 의료 문구 심사용 초안도 전달합니다. AI가 생성하거나 심사한 결과는 오류가 있을 수 있으며 자동화 게이트와 운영자 확인 대상이 됩니다.
  • Telegram: 운영 보고, 게시 실적·실패 알림, 콘텐츠 초안과 승인 요청을 운영자에게 전달합니다.
  • Kakao: 운영자가 승인한 매장별 보고문과 보고서 링크를 설정된 매장 대화방으로 전달합니다.
  • GitHub: 운영자 사진 라이브러리에서 선택한 게시물 사진을 공개 HTTPS 주소로 호스팅하여 Google이 읽을 수 있게 합니다. 매장 순위 보고서도 전용 공개 주소로 게시되므로 링크를 아는 사람은 접근할 수 있습니다. 이 사진·보고서 게시 경로에 리뷰 본문이나 OAuth 토큰을 공개하지 않습니다.
  • Google Business Profile: 제출한 소유자 답글과 로컬 게시물·사진은 Google의 심사를 거쳐 공개될 수 있습니다. Google에 제출하는 것과 실제 공개 상태는 다릅니다.

Google API 데이터 사용 제한

GMB Ops의 Google API 정보 사용 및 다른 앱으로의 전달은 Google API Services User Data Policy와 Limited Use(제한적 사용) 요구사항을 따릅니다. 정책: https://developers.google.com/terms/api-services-user-data-policy

Google에서 얻은 데이터는 운영자가 요청한 프로필 관리 기능을 제공·개선하는 데만 사용하며, 판매, 광고 타기팅 또는 범용 AI 모델 학습 목적으로 사용하지 않습니다. 외부 전달은 위에 설명한 기능 수행에 필요한 범위로 제한합니다. 운영자의 동의·요청에 따른 관리 업무 외의 사람 열람은 보안 조사, 법적 의무 이행 등 정책이 허용하는 경우로 제한합니다.

연결 해제·보관 이력·문의

운영자는 https://myaccount.google.com/permissions 에서 GMB Ops의 Google 앱 접근 권한을 철회할 수 있습니다. 철회는 향후 Google API 접근을 중단시키지만 이미 저장된 로컬 운영 이력을 자동 삭제하지 않습니다. 기존 로컬 이력은 운영자가 제거하거나 지원 창구에 삭제를 요청할 때까지 보관됩니다. 로컬 삭제 요청은 Google에 이미 공개된 답글·게시물이나 외부 서비스에 전달된 자료의 자동 삭제를 의미하지 않습니다. 해당 서비스의 관리 기능과 정책을 함께 확인해야 합니다.
